# Knowledge base (synthetic)

All documents are **synthetic** examples written for this POC. They are reference
material only: agents cite them as `references`, never as facts about an incident, and
nothing in them is ever executed.

- `sop/` — standard operating procedures (human-performed steps)
- `manuals/` — technical background
- `incidents/` — resolved past incidents (synthetic `SIM-HIST-*` identifiers)

Format: first line `# <title>`, optional `Tags: a, b, c` line, then Markdown body.
