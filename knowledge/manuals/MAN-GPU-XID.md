# GPU XID event categories (summary)
Tags: gpu, xid, nvidia, ecc, nvlink, pcie, hardware, application

XID events are driver-reported error codes. Some are commonly associated with application
faults (such as illegal memory accesses), others with hardware conditions (such as
double-bit ECC errors or a GPU falling off the bus). The category is a starting point for
investigation, not a diagnosis. Follow-on XIDs can appear after an earlier error.
